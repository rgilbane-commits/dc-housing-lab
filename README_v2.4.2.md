# DC Housing Lab v2.4.2 — Financial Remediation

Deploy this complete package to the existing Streamlit GitHub repository (replace matching project files). The existing v2.4.1 citywide geography is retained. Recheck Overview, Instructor view, detailed economics and downloadable PDF after deployment.

**Definitions:** Legacy total-cost margin gap = net development cost × (1 + illustrative margin) − grant − stabilized value. New conditional net-cost gap = max(0, net cost − assumed eligible grant) × (1 + margin) − value. The unsubsidized spread = value − net development cost. These are distinct from financing feasibility and equity shortfall.

**Limitations:** No actual grant restrictions, appraised market value, borrower covenants, or investor returns are validated. Browser acceptance required. See QA_AUDIT_REPORT_v2.4.2.md.
